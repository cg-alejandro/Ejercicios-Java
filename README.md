# Ejercicios-Java
Este es mi repositorio personal de ejercicios de Java donde documento mi aprendizaje y practico ejercicios desde los fundamentos hasta conceptos orientados al desarrollo Backend.

El objetivo es construir una base sólida mediante ejercicios prácticos, manteniendo un historial de progreso donde siempre podre volver a revisar como aplique los distintos conceptos de Java.

---USO DE IA---
Para esto he introducido el uso de IA como tutor personalizado con el cual vamos viendo conceptos de un roadmap que planifique, me propone ejercicios y retos de lógica para resolver por mi cuenta, revisa mi codigo y calcula mi porcentaje de independencia de estos ejercicos cuando los corrige.

IMPORTANTE: Estos ejercicios son hechos por mi y corregidos por  IA.
Para asegurar que son resueltos por mi, intento que el porcentaje de independencia sea siempre superior al 95%.
La finalidad no es utilizar IA para que escriba código por mí, sino utilizarla como una herramienta que me permite:
- Resolver problemas por mi cuenta
- Recibir orientación cuando me bloqueo
- Comprender mis errores
- Mejorar progresivamente mi lógica 
- Aprendr a dirigirla y a sacarle partido mas haya de que solo me escriba el código y así poder cimentar mis bases en programación.
